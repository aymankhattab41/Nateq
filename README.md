# ناطق (Nateq / Lord TTS) — محرك نطق وإعلانات صوتية للمكفوفين

تطبيق أندرويد أصلي (Kotlin) يحوّل النصوص إلى كلام، ويُعلن بصوت
لأحداث الجهاز (الوقت، البطارية، الرسائل، المتصل، الإشعارات) لمن يناسبهم ذلك.

- اسم الحزمة: `com.aymankhattab.nateq`
- استهداف: أندرويد 7.0 فأعلى (`minSdk 24`، `targetSdk 37`)
- لغة الواجهة: العربية (افتراضية) والإنجليزية — تبديل فوري داخل التطبيق

---

## الإعلانات المدعومة

| الإعلان | التفاصيل |
|---|---|
| الوقت | فترات دورية (15–60 دقيقة)، جدول هدوء لكل يوم (07:30 بداية/نهاية)، صيغ طبيعية ورقمية |
| البطارية | مستويات 5%–100% قابلة للتحديد، منبه عند مستوى، نطق كنسبة مئوية |
| المتصل | اسم المتصل (مع أسماء مخصصة محفوظة)، تكرار الإعلان، سرعة/نبرة/صوت مستقل |
| الرسائل القصيرة | قراءة كاملة أو المصدر فقط، صوت وسرعة ونبرة مستقلان |
| الإشعارات | قائمة التطبيقات المختارة للقراءة، إذن إعداد النظام |
| ساعة ناطقة | ودجت على الشاشة الرئيسية + بلاطة إعدادات سريعة |
| صحة الجهاز | نطق فوري عند الطلب: مستوى البطارية، حالة الشحن، مساحة التخزين، الذاكرة |
| تحديث ذاتي | بحث وتنزيل وتثبيت الإصدار الجديد من صفحة الإصدارات |
| بعد الإقلاع | إعادة جدولة تلقائية للخدمة الأمامية والإعلانات |

## ميزات إضافية

- **محركان/لغتان**: اختيار محرك TTS ولغة وصوت مستقل لكل من العربية والإنجليزية،
  مع تحويل تلقائي حسب محتوى النص.
- **قاموس النطق**: حفظ نطق الكلمات المخصصة (محرك Aho-Corasick عند الحدود)،
  مع استيراد/تصدير JSON عبر Storage Access Framework.
- **معالجة النصوص**: تحويل الأرقام (منطوقة)، التواريخ، العملات، الوحدات، وساعات.
- **صحة الجهاز عند الطلب**: زر نطق داخل الإعدادات يقرأ حالة الجهاز بالأرقام
  المنطوقة (بالعربية أو الإنجليزية حسب صوت النطق المختار) — بدون أي إذن إضافي.
- **نسخ احتياطي/استعادة**: أي/كل الإعدادات بصيغة JSON من الجهاز نفسه.

## الخصوصية

- **تطبيق محلي 100%**: لا توجد بيانات مستخدمين تُرفع خارجياً — لا إرسال للإعدادات أو
  الأسماء أو القاموس إلى أي خادم.
- **الإنترنت للفحص فقط**: يُستخدم الإذن `INTERNET` حصرياً للتحقق من وجود إصدار
  جديد من صفحة الإصدارات وتنزيل الـ APK؛ لا يخرج منه أي محتوى خاص.
- أسماء المتصلين والقاموس محفوظة في `EncryptedSharedPreferences`
  (مفتاح من Android Keystore، AES-GCM).

## تنظيم الكود

```
app/src/main/java/com/aymankhattab/nateq/
├─ engine/      خدمة TTS (نظامية عبر BIND_TTS_SERVICE)، كتالوج الأصوات، معالج التخليق
├─ providers/   واجهة VoiceProvider + مزوّد محرك النظام (معالجة PCM رقمية)
├─ receivers/   مستقبلات الإعلانات (البطارية، المتصل، الرسائل، الإقلاع، الإشعارات)
├─ settings/    شاشة الإعدادات (قائمة ← شاشة قسم) + مستودع الإعدادات والقاموس
├─ util/        معالجة النصوص والأرقام والإعلانات
└─ widget/      الودجت الناطقة والبلاطة السريعة
```

## ملاحظات للمطوّرين

- **المعماريات المدعومة**: `arm64-v8a` و`armeabi-v7a` (أجهزة 32-بت). محرّكا
  Vocalizer المدمجان لا تتوفّر مكتبتاهما الأصليتان إلا لـ`arm64-v8a`،
  فيسقطان على أجهزة 32-بت بلا انهيار (تُلتقط `UnsatisfiedLinkError`)، بينما
  يعمل محرّك النظام وOCR (tesseract/leptonica) وبقية الميزات طبيعياً.
- الواجهة مبنية لقرّاء الشاشة: أهداف لمس ≥ 48dp، `contentDescription` لكل عنصر،
  `accessibilityHeading` للأقسام، وإعلانات `announceForAccessibility` عند التغيير.
- جميع الأحجام النصية بـ `sp` — تستجيب لضبط خط النظام تلقائياً.
- لا يوجد `App Check` في المشروع (ممنوع حسب قواعد العمل) ولا خطوط مضمّنة.
- شاشة الإعدادات من مستويين داخل الـ Fragment نفسه (`openSection`/`showHome`)
  مع إعادة توجيه تركيز الوصول عند فتح/إغلاق أي قسم.
- البناء: `.\gradlew.bat :app:assembleRelease` → `app/build/outputs/apk/release/nateq.apk`
  (R8 + تصغير الموارد مفعّلان في الـ release).

## خدمات الشاشة وإمكانية الوصول

- **اختصارات مفاتيح الصوت القابلة للتهيئة**: جدول ربط (ضغط مطوّل/مزدوج/ثلاثي/
  المفتاحان معاً) لكل إيماءة فعل، مع شاشة اختبار فوري، ويُستهلك المفتاح عند
  اكتمال الإيماءة فقط فلا يتغيّر مستوى الصوت قبل تحقّق الاختصار.
- **القائمة السريعة وزر إمكانية الوصول**: نافذة إجراءات عائمة تنطق الأفعال
  المتاحة، مربوطة بزر الوصول وبلاطة الإعدادات السريعة.
- **القراءة الحية والدردشة**: قراءة الرسائل الجديدة، وتوسيع المقتطع، وملخّص
  الدردشة (أسماء المرسلين وعدد الرسائل) مع تثبيط التكرار.
- **أصوات جهات الاتصال** (`a11y_contact_voices`): صوت مستقل لكل جهة اتصال
  يُطبَّق على نطق مكالماتها ورسائلها بأولوية تسبق صوت الفئة، مخزَّنٌ محلياً
  في `ContactVoiceStore` ومفتاحُ البحث رقمٌ مُطبَّع. ويُضاف/يُحرَّر من
  **محرّر صوتٍ كامل** (`VoiceProfileEditorDialog`).
- **ملفات التطبيقات والتبديل التلقائي** (`a11y_app_profiles`,
  `a11y_auto_profile_switch`): صوتٌ ومستوى تفصيل لكل تطبيق (`AppProfileStore`)
  يُطبَّق حسب التطبيق الأمامي عبر `A11yVoiceResolver`.
- **إجراءات مفاتيح المكالمة**: الرد أو الرفض بمفتاح الصوت أثناء الرنين
  (إذن `ANSWER_PHONE_CALLS`) مع إمكانية تبديل المفتاحين.
- **إعلان مسار الصوت والبلوتوث**: عند اتصال/فصل جهاز صوتي (أندرويد 12+
  يحتاج `BLUETOOTH_CONNECT`).

### حسم صوت الإعلانات

`VoiceProfileResolver.effective` يحسم الأولوية مركّزاً:
**الافتراضي ← الفئة ← ملف التطبيق ← جهة الاتصال** — كل طبقة تُطبَّق فوق
الأثقل منها فلا يُغيَّر إلا الحقل المحدَّد.
